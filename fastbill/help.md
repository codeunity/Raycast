# Connect your Fastbill account

1. Sign in at [my.fastbill.com](https://my.fastbill.com).
2. Open **Einstellungen → Übersicht** (Settings → Overview) and copy the **API-Key**.
3. Paste it into the **API Key** field, and enter the email address of your Fastbill user in the **Email** field.

Both values are used for HTTP basic authentication against the
[Fastbill API](https://apidocs.fastbill.com/). The API key belongs to the
account, the email address identifies the user making the request — so both
have to match the same Fastbill account.
